Một env, một lệnh chạy

01

Chuẩn bị .env

Máy mới copy .env.example thành .env. Đã có env thì giữ nguyên; đặt ADMIN_PASSWORD riêng, nên dài ít nhất 12 ký tự.

cp .env.example .env
02

Chạy Docker

Mở Docker Desktop. Lần đầu hoặc đổi dependencies/Dockerfile chạy có --build.

docker compose up -d --build
03

Đăng nhập

Mở URL sau khi container khởi động thành công. Dùng ADMIN_USERNAME và ADMIN_PASSWORD trong .env.

http://127.0.0.1:9000
docker compose ps
docker compose logs -f app
# Các lần sau
docker compose up -d
# Dừng
docker compose stop

Container tự chạy lại khi Docker Desktop mở nếu chưa bị stop thủ công. Entrypoint tạo DB nếu thiếu, giữ key, chạy migration và seed admin/demo. Không reset DB.

Admin được cập nhật từ env mỗi lần start. Giữ ADMIN_PASSWORD trong .env; đổi mật khẩu trên app có thể bị đưa về giá trị env ở lần start sau. Không commit/chia sẻ env, mật khẩu hoặc key.

Sửa mã nguồn và Vite

Compose mount app, bootstrap/app.php, config, database, public, resources, routes và artisan; vendor ở image. Sửa PHP/Blade/CSS/JS trong public rồi refresh. Đổi dependencies/Dockerfile cần rebuild.

Giao diện hiện tại dùng public, không cần Vite. Nếu làm assets resources:

docker compose --profile dev up -d frontend
docker compose logs -f frontend
docker compose run --rm frontend npm run build

App container không có npm. Public bind mount ưu tiên host; build assets vào public/build trên host khi cần, không dựa vào artifacts chỉ nằm trong image.

Override debug tùy chọn:

docker compose -f compose.yaml -f compose.dev.yaml up -d

Trở về mặc định: docker compose up -d. Không bật debug khi chia sẻ LAN.

Dữ liệu demo và hóa đơn

Demo tạo 5 tầng/14 phòng khi property chưa có tầng: 101–104, 201–203, 301–302, 401–404, 501. Đã có cấu trúc thì giữ nguyên. Giá mẫu cần kiểm tra tại /rooms: phòng 3.000.000 đ, điện 3.200 đ/kWh, nước 17.000 đ/m³, xe 120.000 đ, rác 30.000 đ.

Không seed thử vào DB muốn giữ sạch. db:seed chỉ seed demo; admin seed riêng. Chỉnh cấu trúc tại /property-structure; phòng có lịch sử chỉ ngừng sử dụng.

  1. Chọn kỳ tại /billing-periods
  2. Ghi điện nước từng phòng
  3. Xem hóa đơn từ snapshot
  4. In A5 / 3 phiếu A4 hoặc xuất XLSX/PDF/DOCX

Bản in/PDF không gắn nhãn nháp; trạng thái nội bộ và snapshot vẫn bảo toàn lịch sử. Quản lý hiển thị “Đã tạo”; Excel dùng trạng thái reading hoặc “Đã tạo” khi thiếu reading. Word hiện không có nhãn nháp.

Dữ liệu còn nguyên khi dừng app

Nơi lưuNội dungBảo toàn
database/ trên hostSQLite và WAL/SHMKhông tự xóa file khi stop/down/rebuild
app-data volumeKey + /data/backupsGiữ nếu không down -v
app-storage volumeStorage LaravelGiữ nếu không down -v

Không dùng docker compose down -v. Không đặt DB đang chạy trong cloud sync, OneDrive/Google Drive/Dropbox, SMB/NFS. DB và backup nằm ngoài public; không commit SQLite/WAL/SHM/logs/backup/key.

docker compose exec app php artisan app:backup-database

Backup dùng VACUUM INTO, kiểm tra integrity và khóa ngoại trước khi công nhận/dọn retention. Mặc định giữ 30 bản, đổi DB_BACKUP_RETENTION hoặc --retention=60. Chỉ dọn file đúng mẫu.

Tạo thư mục backups trên host, chép đúng tên được lệnh báo rồi mới chép snapshot lên cloud. Giữ ít nhất một bản ngoài máy và thử restore trên bản sao.

docker compose cp app:/data/backups/TEN-BACKUP.sqlite ./backups/TEN-BACKUP.sqlite
Khôi phục thay toàn bộ dữ liệu — dừng app trước
  1. Tạo backup hiện trạng và chép ra host.
  2. Dừng app bằng docker compose stop app.
  3. Chép backup chọn vào /data/restore.sqlite của container đã dừng.
  4. Thay database, xóa WAL/SHM cũ, đặt owner/quyền khi app vẫn dừng.
  5. Start lại; kiểm tra logs, đăng nhập, kỳ gần nhất và chỉ số phòng. Start cũng chạy migration/seed.

Không ghi đè DB khi app chạy. Xem lệnh restore đầy đủ trong nguồn Markdown.

Điện thoại cùng Wi-Fi: tùy chọn LAN

Mặc định chỉ truy cập trên máy. Muốn LAN thì đặt private IP cụ thể, giữ debug false:

APP_BIND_IP=192.168.1.20
APP_URL=http://192.168.1.20:9000

# Sau khi sửa env
docker compose up -d

Điện thoại mở URL trên. Dùng DHCP reservation; firewall chỉ Private/Home, TCP 9000, giới hạn subnet nếu có. Không tự bind 0.0.0.0. Nếu người thuê dùng Wi-Fi chung, tách private SSID/VLAN khỏi guest.

Không port-forward/NAT, DMZ, UPnP mapping, public proxy hay Internet tunnel cho app. Laravel development server phục vụ local, không đưa ra Internet công cộng.

SQLite và kiểm tra mã

WAL, foreign keys, busy_timeout 5000ms, transaction IMMEDIATE, synchronous NORMAL phù hợp hai thiết bị ghi ngắn. SQLite chỉ có một writer; writer thứ hai chờ tối đa 5 giây. DB bận thì đợi/thử lại; nếu lặp lại kiểm tra import/writer bất thường và nơi lưu DB.

NORMAL giữ nhất quán nhưng mất điện có thể mất giao dịch vừa ghi cuối: backup định kỳ, dùng UPS nếu cần. Không đổi hệ DB chỉ vì dùng hai thiết bị.

php artisan test
php vendor/bin/pint --test
docker compose config --quiet

Test dùng SQLite :memory:, cần PHP ≥8.3 và vendor dev trên host; không thử trên dữ liệu thật. Máy này có PHP 8.4 tại /opt/homebrew/opt/php@8.4/bin/php; PHP mặc định hiện lỗi. Image app chỉ có runtime dependencies, không có test tooling. config --quiet tránh in secrets.
