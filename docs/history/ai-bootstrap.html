http://127.0.0.1:9000 là URL theo cấu hình khi app được start. nhatro.localhost chỉ là đề xuất. Chưa kiểm chứng HTTP app/proxy qua IPv4, IPv6 và browser. Không start Docker trên dữ liệu thật vì entrypoint tự migrate và seed.

Đường đi để chuẩn hóa runtime

  1. Review identity

    Nhà trọ 441; services app và frontend. Xử lý trạng thái discovery rồi chạy lại allocator.

  2. Kiểm tra và reserve

    Toàn block IPv4/IPv6 và Docker. Quy ước x000 app, x030 frontend; SQLite không expose port.

  3. Đồng bộ cấu hình

    Compose, env, Vite/HMR và docs dùng allocation xác nhận. Giữ credentials, DB và bind loopback.

  4. Kiểm chứng route

    Thêm proxy khi được phép, kiểm tra origin/cookie/CORS và phản hồi HTTP mong đợi ở cả hai IP family cùng browser.

Quy trình onboarding Dev Hub yêu cầu phạm vi đăng ký/migration rõ trước khi ghi cấu hình. Phần này là đề xuất. Rollback bằng snapshot cấu hình; không xóa DB hoặc volume.

Tooling và cấu hình
  • PHP 8.4.18 có sẵn chạy được Laravel 13.24.0. PHP mặc định 7.4 lỗi libffi; không đổi hệ thống.
  • RTK không có trong PATH/vị trí phổ biến, dùng fallback trực tiếp.
  • Compose mặc định và dev qua config --quiet; không in secrets.
  • Pint báo lỗi có sẵn tại PropertyStructureController.php và UpdateRoomSettings.php; không sửa ngoài scope.
  • Skill kiểm tra bằng validator trong venv tạm có PyYAML. Kiểm tra diff, links, favicon và HTML tĩnh; chưa xem render vì browser chặn URL file://.
  • Chưa build/start Docker hoặc npm build; chưa xác minh runtime app/proxy.
